# 让中文排版回到该有的样子

好的排版不该被读到，读者只应看到文字。Markview 以整段为单位求解断行：不是逐行贪心
填充，而是权衡整段的词间距，让每一行都同样舒展。较长的西文单词会在合适的位置断字，
中文标点则遵守各自的行首行尾规则——开括号「（《不会孤零零地落在行尾，句号、逗号和
右括号也不会挤到下一行的开头。

行内公式 $E = mc^2$ 与正文共享基线，而 $\frac{a+b}{\sqrt{x_1^2+x_2^2}}$ 只在必要时
撑高这一行。汉字与拉丁字母之间留有自然的间隙，**粗体**与*斜体*紧贴中文也能正确闭合。

$$
\int_{-\infty}^{\infty} e^{-x^2}\,dx = \sqrt{\pi}
$$

> 版式的目的是让阅读变得轻松。读者应当忘记页面，只记住文字。

标点与间隙只是细节，整段的均匀才是阅读舒适的关键。Markview 在整段范围内分配每一行的
松紧：有的行略微收紧，有的行略微放松，右边界因此整齐，而不会出现一道忽宽忽窄的白缝。

简体、繁体与日文各有各的标点惯例：逗号一类的符号在中国大陆和日本会让出半个字宽，
在台湾则居中排布。`SC`、`TC`、`JP` 三种约定各有自己的字体与标点规则，切换之后整篇
文档重新排版。
