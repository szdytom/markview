# 让笔记连成一片

一个好想法，很少只停留在一页纸上。书中的一段话引出一个问题，一个问题变成一篇札记，
这篇札记又与过去读过的内容遥相呼应。沿着这些线索，让零散的记录慢慢长成自己的知识库。

## 顺着线索读下去

留一份[[阅读清单]]，记下读书时的观察，再顺着双链回到相关的笔记。
把几篇文章并排放在标签页里，让一个想法，自然地带出下一个。

> [!tip] 一座陪你生长的书房
> 从一个 Markdown 文件夹开始，逐渐加入章节、图片和链接。
> 熟悉的目录，就是随时可以走进来的书房：翻阅、重温，让想法彼此相连。

## 把值得记住的话留下来

一个值得留下的观察：==阅读，是跨越页面的对话==。
清晰的标题、恰到好处的强调，再加上一条通往旧笔记的链接，明天回来时，就能继续这场对话。

| 留在手边 | 重读的理由 |
| --- | --- |
| 读书笔记 | 一段值得回味的文字 |
| 研究札记 | 答案背后的那个问题 |
| 日常观察 | 当时留意到的小小细节 |

回到[[从这里开始|我的书房]]，或翻开[[研究札记/值得留下的问题]]。
